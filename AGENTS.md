# Talent Platform development workspace

This repository owns the consolidated platform and integration work. Existing source repositories remain historical/vertical owners until a documented adapter or module migration changes that responsibility. Do not edit their dirty branches, migrate their databases, or copy secrets or full candidate evidence stores as incidental setup.

The initial operating constraint is public professional sources only. Published contact observations retain URL, timestamp and quote/context; deliverability stays unknown. No guessed email, LinkedIn scraping, hidden paid fallback, external messages, or automatic hiring decisions. Recruiters explicitly keep people, review contact associations, and change pipeline stages. Suppression is global and sticky.

Source facts, identity, recruiter notes, and derived match explanations are distinct. Treat imports as observations with original project references. Preserve original review/exclusion states and negative results. No fabricated candidates, scores, demographic/protected-characteristic fields, or biometric inference in the normal workspace.

Verify the browser workflow and appropriate API/denial checks. Synthetic tests use temporary databases. Preserve existing source/data snapshots; commit only named source/docs paths, never environment files or stores. A working local milestone does not establish competitor superiority, production readiness or recruiting outcomes.

Run `npm start`, `npm test`, `npm run check`, and `npm run doctor`. Read `docs/CONSOLIDATION.md`, `docs/BUILD_STATUS.md`, and current research before extending integrations.
